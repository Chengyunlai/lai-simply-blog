## 为什么需要个人博客？

在这个信息爆炸的时代，拥有一个属于自己的博客非常重要：

1. **记录学习过程** - 把学到的知识写下来，加深理解
2. **分享经验** - 帮助其他人解决问题
3. **建立个人品牌** - 展示你的技术能力

## 技术栈选择

我选择了以下技术栈：

- **Next.js** - React 框架，支持 SSR 和静态导出
- **TypeScript** - 类型安全，减少 bug
- **MDX** - Markdown + JSX，灵活排版

## 开始搭建

首先创建项目：

```bash
npx create-next-app@latest my-blog
cd my-blog
npm install next-mdx-remote gray-matter
```

搭建个人博客并不难，关键是坚持写作。希望这篇文章对你有帮助！
