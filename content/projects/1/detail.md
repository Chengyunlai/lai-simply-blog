## About this project

Lai Simply Blog is a small, content-first blog starter. Write posts in Markdown, configure the site in one place, and deploy it to a private server, Vercel, or GitHub Pages.

### Highlights

- English and Chinese routes
- Four article rendering styles
- Theme switching and responsive layout
- Projects organized as independent content folders

The project metadata is kept in `meta.json`, while this file is optional: remove it when a project only needs a short card on the projects page.
